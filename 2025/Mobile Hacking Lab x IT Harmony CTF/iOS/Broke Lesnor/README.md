# Broke Lesnor

```
Step into the ring with Broke Lesnor, the world's most budget-conscious wrestling hero and the star of this iOS exploitation challenge. 

Investigate the Broke Lesnor iOS application and discover a way to trigger its hidden flag screen.
How you get there, that's for you to figure out.

This intentionally vulnerable fan app hides a secret deep within its code, waiting for a challenger skilled enough to uncover it.
```

**Objective:**
Your mission is to leverage multiple memory corruption vulnerabilities in the "Broke Lesnor" iOS application to bypass ASLR and redirect execution to the hidden `flag()` function, ultimately revealing the flag.
