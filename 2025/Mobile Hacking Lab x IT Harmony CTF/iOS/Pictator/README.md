# Pictator

```
This challenge focuses on the Pictator app, a secure communication tool utilized by a dictator's army. It processes images using the proprietary library to securely transmit the files over the network. However, there exists a Use After Free vulnerability which leads to severe impact. Your objective is to exploit this UAF bug and retrieve the hidden flag.
```
